---
title: Local Quickstart
description: Run the project locally with .NET Aspire and development toolchain
---

## Prerequisites

* .NET SDK (latest supported)
* Node.js (latest LTS)
* pnpm
* Docker

## Steps

1. Install dependencies.
2. Restore .NET tools.
3. Run the AppHost project.
4. Open frontend and backend endpoints from Aspire dashboard.
